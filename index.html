How to use

① Load a GPX file
Drag and drop your GPX track onto the drop zone, or click to browse.
② Interpolation — Method
None — raw GPX as recorded.
Linear — adds points in straight lines for uniform spacing.
Spline — smooth curve through points, best for sparse files.
Spacing
Target distance between interpolated points. 10 m is a good default.
③ Min angle
Minimum bearing change to count as a turn. Start at 30°, lower for more turns.
Min dist
Minimum distance between turns. Raise if tulips appear too close together.
④ Generate roadbook
Processes the GPX and builds the tulip table.
⑤ Add signals (⊕ button)
Click the red ⊕ button in any row to open the signal picker. Click a symbol to place it in the tulip cell. Click a placed symbol to remove it.

Opens a preview window. Click “Save as PDF”, then in the print dialog choose Destination → Save as PDF.
